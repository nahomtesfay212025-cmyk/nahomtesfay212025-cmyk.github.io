Nahom is a 4.0 GPA Computer Science student and Presidential Scholar with hands-on experience

## ✨ Features

- Modern, fully responsive design (looks great on desktop, tablet, and mobile)
- Animated futuristic background built with the HTML Canvas API
- Smooth scroll-reveal animations and an accessible mobile navigation menu
- Sections for About, Skills, Projects, Experience, Achievements, Education, and Contact
- Downloadable résumé and direct links to live client projects

## 🛠️ Built with

- **HTML5** — semantic structure and content
- **CSS3** — custom theming (CSS variables), responsive grid layout, and animations
- **JavaScript** — interactive particle-network background and UI behavior
- **GitHub Pages** — free static hosting

No frameworks and no build step — fast, lightweight, and easy to maintain.
